# Ket OS

量子操作系统。clone 后**不用装任何依赖**。量子内核（精确态矢量、无噪声、F=1）已经打进 `KetOS.html`。

## 启动

双击其一：

- Windows：`START.bat`
- macOS：`START.command`（没有权限就先执行 `chmod +x START.command`）
- Linux：`START.sh`

也可以直接用浏览器打开 `KetOS.html`。

## 功能

多窗口、缩放、24-bit 量子 ALU 计算器、逻辑器、文件系统、Grover、传送、终端、任务管理器（每秒刷新 Q-CPU / Q-MEM / 比特）。
